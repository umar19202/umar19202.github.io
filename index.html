Multi-Tenant Healthcare ERP

ExtraTrik

The Turkish Healthcare ERP

A multi-tenant communication ERP serving multiple Turkish healthcare clinics from one codebase, each with a fully isolated dashboard, data store, and webhook namespace behind a custom centralized authentication layer. At its core is a real-time, 3-column SPA dashboard built with JavaScript, jQuery, and Axios — unifying Zoho CRM with omnichannel chat (WhatsApp, Messenger, Instagram), Twilio video calling, and OpenAI-powered translation and grammar-checking, all updating live without a single page reload. The platform was built to scale: reporting infrastructure handles 1M+ chat rooms and 20M+ messages, with MySQL temporary tables, Redis caching, and automated cron tasks cutting critical query filter times from timeouts down to seconds. AWS S3 secures every chat media upload, attachment, and call recording across all clinic tenants, while Laravel Queues drive asynchronous bulk-import workflows with custom start, pause, and resume state handling. The whole system is backed by PHPUnit test suites and a GitHub Actions CI/CD pipeline maintained across a remote Agile team in Istanbul.
